# Locktober Control App

A React/Next.js application for managing the Locktober control schedule.

## Getting Started

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Deploy on Vercel

This project is configured to deploy on [Vercel](https://vercel.com).

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically build and deploy on each push to `main`

## Features

- October schedule with 31 daily activities
- Period mode toggle with alternative activities
- Dice lottery roller for release outcomes
- Progress tracking with points system
- Week-by-week organization
- Responsive design with Tailwind CSS

## Tech Stack

- Next.js
- React 18
- Tailwind CSS
- Lucide React Icons
